## 详细描述

### 1. NormalAttack — 普通攻击

| 属性 | 值 |
|---|---|
| **技能类型** | SingleAttack（单体攻击） |
| **目标类型** | SingleEnemy（敌方单体） |
| **等级范围** | L1 / L2 / L3 |
| **法力消耗** | 无 |

**效果：** 对敌方单体造成伤害。

| 等级 | 伤害倍率 |
|---|---|
| L1 | 100% 攻击力 |
| L2 | 150% 攻击力 |
| L3 | 200% 攻击力 |

**AI 优先度：** 优先攻击低血量目标。`priority = 50 + (1 - HP比例) × 30`

---

### 2. Shield — 护盾

| 属性 | 值 |
|---|---|
| **技能类型** | Defense（防御） |
| **目标类型** | SingleAlly（友方单体） |
| **等级范围** | L1 / L2 / L3 |

**效果：** 消耗法力，为目标附加护盾值。

| 等级 | 法力消耗 | 护盾比例（最大HP） |
|---|---|---|
| L1 | 3 | 10% |
| L2 | 4 | 15% |
| L3 | 5 | 20% |

**AI 优先度：** 优先保护低护盾、低血量目标。综合考虑护盾缺口和血量缺口。

---

### 3. EquivalentExchange — 等价交换

| 属性 | 值 |
|---|---|
| **技能类型** | Support（辅助） |
| **目标类型** | SingleSelf（自身） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 无 |

**效果：** 交换自身当前 HP 比例和 MP 比例，然后扣除 10% 最大法力值。

**AI 优先度：** 当法力比例远高于血量比例时使用。`priority = min((MP比例 - HP比例) × 85, 80)`，若差值为负则降至 5。

---

### 4. PenetrateArrow — 贯穿之箭

| 属性 | 值 |
|---|---|
| **技能类型** | Spread（扩散） |
| **目标类型** | SingleEnemy（敌方单体） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 25 |

**效果：** 对与施法者同列的所有敌方单位造成 **250% 攻击力 + 10% 目标最大HP** 的伤害。

**AI 优先度：** 偏向同列敌人多时使用。同列敌人越多，评分越高。

---

### 5. Heal — 治疗

| 属性 | 值 |
|---|---|
| **技能类型** | Healing（治疗） |
| **目标类型** | SingleAlly（友方单体） |
| **等级范围** | L1 / L2 / L3 |

**效果：** 消耗法力，恢复目标一定比例的最大 HP（不会超过上限）。

| 等级 | 法力消耗 | 回复比例（最大HP） |
|---|---|---|
| L1 | 3 | 15% |
| L2 | 4 | 20% |
| L3 | 5 | 25% |

**AI 优先度：** 优先治疗血量低的友方。HP ≥ 90% 时优先度为 5；否则 `(1 - HP比例) × 85`。

---

### 6. SandStorm — 沙暴

| 属性 | 值 |
|---|---|
| **技能类型** | AoE（群体攻击） |
| **目标类型** | AllEnemies（敌方全体） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 25 |

**效果：** 对敌方全体造成 **200% 攻击力** 的伤害。

**AI 优先度：** 敌方存活数量越多，优先度越高。1 个敌人时仅 20；`min(敌方数 × 22, 85)`。

---

### 7. FlashStrike — 闪击

| 属性 | 值 |
|---|---|
| **技能类型** | Support（辅助） |
| **目标类型** | SingleAlly（友方单体） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 10 |

**效果：** 驱散目标所有负面效果（`BattleEffectType.Negative`），并将其 `RemainingCost` 重置为 0（即下次立即行动）。

**AI 优先度：** 目标负面效果越多越优先。无负面时仅 10；`min(负面数 × 25, 80)`。

---

### 8. ManaDrain — 吸魔

| 属性 | 值 |
|---|---|
| **技能类型** | SingleAttack（单体攻击） |
| **目标类型** | SingleEnemy（敌方单体） |
| **等级范围** | L1 / L2 / L3 |
| **法力消耗** | 无 |

**效果：** 吸取目标百分比最大法力值，回复给施法者（不超过各自上下限）。

| 等级 | 吸取比例（最大Mana） |
|---|---|
| L1 | 10% |
| L2 | 15% |
| L3 | 20% |

**AI 优先度：** 自身法力越低越优先。自身 MP ≥ 80% 时为 15；否则 `15 + (1 - MP比例) × 70`。

---

### 9. AtkStrongUp — 你被强化了！快上！

| 属性 | 值 |
|---|---|
| **技能类型** | Support（辅助） |
| **目标类型** | SingleAlly（友方单体） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 10 |

**效果：** 为目标施加 `AtkMultUp` 效果：攻击力 ×200%，持续 1 回合。

**AI 优先度：** 固定 65。

---

### 10. ThornsWrap — 荆棘缠绕

| 属性 | 值 |
|---|---|
| **技能类型** | SingleAttack（单体攻击） |
| **目标类型** | SingleEnemy（敌方单体） |
| **等级范围** | L1 / L2 / L3 |

**效果：** 消耗法力，为目标施加 2 层 `Thorns` 效果（每回合受到百分比攻击力的持续伤害），持续 2 回合。最多叠加 5 层，可驱散。

| 等级 | 法力消耗 | 每层伤害比例（攻击力） |
|---|---|---|
| L1 | 5 | 50% |
| L2 | 6 | 70% |
| L3 | 7 | 90% |

**AI 优先度：** 优先对高血量敌人施放。HP < 30% 时仅 10；`20 + HP比例 × 60`。

---

### 11. TheLastStand — 背水一战

| 属性 | 值 |
|---|---|
| **技能类型** | Support（辅助） |
| **目标类型** | AllAllies（友方全体） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 20 |

**效果：** 为全体友方施加两个效果（持续 3 回合）：

- `DmgBonusUp`：**造成伤害 +100%**
- `DmgReductionDown`：**受到伤害 +50%**

**AI 优先度：** 友方存活数越多越优先。1 人时 15；`min(友方数 × 20, 80)`。

---

### 12. Armageddon — 哈米吉多顿

| 属性 | 值 |
|---|---|
| **技能类型** | AoE（群体攻击） |
| **目标类型** | AllEnemies（敌方全体） |
| **等级范围** | L1（唯一） |
| **法力消耗** | 见效果 |

**效果：**

- **前提条件：** 己方仅剩 1 个存活单位
- **代价：** 施法者 HP 降为 1，Mana 降为 1
- **伤害：** 对敌方全体造成 **500% 目标最大HP** 的伤害

**AI 优先度：** 固定 95（非常高，绝境时优先使用）。
